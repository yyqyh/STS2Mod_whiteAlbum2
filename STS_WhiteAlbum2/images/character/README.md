# Character static art replacement guide

Each character folder contains the same set of static PNG placeholders.
Replace them with real art later using the same paths / file names.

## setsuna

Files under `res://STS_WhiteAlbum2/images/character/setsuna/`:

- `character_select_setsuna.png` — character-select portrait
- `character_select_setsuna_locked.png` — locked character-select portrait
- `character_icon_setsuna.png` — top-panel icon
- `character_icon_setsuna_outline.png` — top-panel icon outline
- `map_marker_setsuna.png` — run-map marker
- `select_bg.png` — static character-select background placeholder
- `character.png` — static combat portrait placeholder
- `energy_icon.png` — energy icon placeholder
- `shop.png` — merchant-room portrait placeholder
- `rest.png` — rest-site portrait placeholder
- `card_trail.png` — card-trail particle placeholder
- `arm/point.png` — multiplayer pointing hand
- `arm/rock.png` — multiplayer rock hand
- `arm/paper.png` — multiplayer paper hand
- `arm/scissors.png` — multiplayer scissors hand
